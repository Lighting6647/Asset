แจ้งเตือนอุปกรณ์ผ่าน Lark

จับคู่ชื่อผู้ถืออุปกรณ์กับอีเมล Lark หรือ Open ID แล้วเปิดการแจ้งเตือน ระบบเริ่มเตือนก่อนครบกำหนด 3 วัน วันละครั้งหลัง 09:00 น. หยุดเตือนเมื่อยืนยันแล้ว และเริ่มใหม่เมื่อใกล้ถึงรอบถัดไป

รายชื่อที่คล้ายกันหรือมีชื่อเล่นต่างกันจะอยู่คนละแถว User ID เดียวผูกได้หลายแถวสำหรับผู้ถืออุปกรณ์หลายชิ้น ระบบจะรวมลิงก์ที่ถึงกำหนดส่งให้บัญชีนั้นในข้อความเดียว กรุณาตรวจบัญชีผู้รับก่อนเปิดส่ง

รายงานสรุปทั้งระบบส่งให้อำพล แซ่แฮเท่านั้น วันละครั้งหลัง 09:00 น. เมื่อเซิร์ฟเวอร์ทำงาน แยกจากลิงก์เตือนพนักงาน

นำเข้าเฉพาะชื่อที่ตรงกันอย่างชัดเจน รายชื่อใหม่จะยังปิดส่งไว้ และไม่เปลี่ยนสถานะเปิดส่งของบัญชีเดิม

กรอกรหัสผ่านแล้วโหลดรายชื่อ
ชื่อ / อุปกรณ์รอยืนยันประเภทบัญชีบัญชี Larkเปิดส่ง / บันทึกการส่งล่าสุด

ใช้บัญชี Lark ของพนักงาน ไม่ใช่ชื่อที่แสดงในแชท การทดสอบการเชื่อมต่อจะตรวจ App ID / App Secret โดยไม่ส่งข้อความ
